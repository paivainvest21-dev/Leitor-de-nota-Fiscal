# 🧾 Leitor de Nota Fiscal

Um aplicativo automatizado desenvolvido para extrair, ler e processar dados de notas fiscais de forma rápida e eficiente.

---

## 🚀 Funcionalidades

* **Leitura Automatizada:** Extração de informações essenciais de notas fiscais.
* **Organização de Dados:** Processamento estruturado para facilitar consultas e relatórios.
* **Agilidade:** Redução do trabalho manual de digitação e conferência de documentos fiscais.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** HTML,CSS, Java Script.
